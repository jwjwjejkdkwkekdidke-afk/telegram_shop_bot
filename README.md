# Stars Shop Bot

Готовый стартовый Telegram-магазин на Python + aiogram 3.

## Уже реализовано

### ⭐ Stars
- Купить себе / купить другу
- Для друга бот спрашивает username
- Пакеты Stars и цены
- Выбор способа оплаты: карта / TON

### 💎 TON / внутренние TG GRAM(TON)
- Экран выбора типа GRAM(TON)
- RU-style описание из ТЗ
- Ввод количества от 1 до 200
- Расчёт по курсу 1 GRAM(TON) = 124.31 руб.
- Запрос Telegram username получателя
- Выбор оплаты картой или в TON

### 🧬 Premium
- Предупреждение об отсутствии активной подписки
- Купить себе / купить другу
- Для друга запрос username
- 3 месяца — 1099 ₽
- 6 месяцев — 1449 ₽
- 12 месяцев — 2499 ₽
- Выбор оплаты картой или в TON

### 🎟 ROBLOX
- Сначала выбор региона
- Сейчас доступен RU
- Каталог пакетов Robux
- Выбор оплаты картой или в TON

## Важное
Платёжные реквизиты пока показываются из `.env`. Автоматическая проверка платежей и автоматическая выдача товара ещё не подключены.

Для запуска:
1. `pip install -r requirements.txt`
2. Скопируй `.env.example` в `.env`
3. Вставь BOT_TOKEN
4. Заполни YOOMONEY_CARD и TON_WALLET
5. `python bot.py`
